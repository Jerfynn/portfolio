Underwater and surface vehicles

Ground stations, sonar tools and onboard software for marine vehicles.

SonarViewer

Desktop app for the Blue Robotics Ping360 scanning sonar. It draws a live polar sweep and a raw echo plot, tracks targets while ignoring the transmit pulse, scans custom sectors, logs every scan to CSV and replays recorded sessions.

Python, PySide6, brping

Code on GitHub

Vessel onboard backend

The software that runs on the vehicle: separate modules for AHRS, GPS, battery management, chamber temperature and thrusters, with serial-port auto-detection, a network server for the ground station, an encrypted link and an autonomous mode.

Python, serial, TCP/UDP networking

Code on GitHub

GliderView

Telemetry station and 3D attitude viewer for underwater gliders. It reads ten channels over a serial port in CSV, JSON or tagged formats, covering roll, pitch, heading, depth, temperature, pressure and battery health.

Python, QtPy, PyOpenGL, PyQtGraph

Code on GitHub
